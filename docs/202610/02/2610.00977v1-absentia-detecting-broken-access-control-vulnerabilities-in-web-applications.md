## 摘要
失效访问控制，即授权失败，是最常见的Web安全风险之一。与注入（不可信输入流入危险操作）不同，授权是一种关系：谁可以对什么进行操作，而不是数据如何流动。每个应用自行决定这种关系，因此任何预先写好的规则都无法套用到下一个应用。LLM智能体可以从代码中推断出这种关系，但如果没有系统化方法来覆盖整个应用并对需要检查的内容进行优先级排序，其搜索就会缺乏方向，访问控制缺陷也就无法被发现。我们提出ABSENTIA，一种安全脚手架，可将通用LLM智能体转变为针对Web应用后端的系统性漏洞检测器，由维护代码的开发人员和安全工程师作为审计运行。在其指导下，智能体构建一个图，将应用的路由映射到其背后的代码。ABSENTIA随后逐路由工作，应用不变式证伪：它推断代码本应满足的性质，并在某一性质未被强制执行时，报告该路由以供维护者审查。我们还发布了BAC-Bench，一个包含30个失效访问控制公告的基准，覆盖25个代码库、3种语言和9个框架，每项均于2025年或之后发布，经人工审计员验证，并与其修复提交配对，因此只有标记出易受攻击版本而非已修复版本才能得分。ABSENTIA召回了其中19个，在配对计分下为17个，LLM验证器确认了其51%的发现。CodeQL和Semgrep没有召回任何一项，而同一模型上的非结构化智能体召回了3个。在OWASP Benchmark注入类别中，ABSENTIA在Python中领先于专用分析器，在Java中仅落后于CodeQL和IRIS。

## Abstract
Broken access control, the failure of authorization, is one of the most prevalent web security risks. Unlike injection, a flow of untrusted input into a dangerous operation, authorization is a relation: who may act on what, not how data moves. Each application decides that relation for itself, so no rule written in advance carries to the next. An LLM agent can infer it from the code, but with no systematic way to cover the application and prioritize what to inspect, its search stays undirected and access-control flaws go undetected.   We present ABSENTIA, a security scaffolding that turns general LLM agents into systematic vulnerability detectors for the backend of web applications, run as an audit by the developers and security engineers who maintain the code. Under its direction, the agents build a graph that maps the application's routes to the code behind them. ABSENTIA then works route by route, applying invariant falsification: it infers the properties the code is meant to satisfy, and where one is not enforced, reports the route for maintainer review.   We also release BAC-Bench, a benchmark of 30 broken access control advisories across 25 repositories, 3 languages, and 9 frameworks, each published in 2025 or later, verified by a human auditor, and paired with its fixing commit, so credit requires flagging the vulnerable version and not the fixed one. ABSENTIA recalls 19 of them, 17 under paired credit, and an LLM verifier confirms 51% of its findings. CodeQL and Semgrep recall none, and an unstructured agent on the same model recalls 3. In the OWASP Benchmark injection categories, ABSENTIA leads the dedicated analyzers in Python and trails only CodeQL and IRIS in Java.
