## 摘要
人工智能工作负载的快速增长，对安全且可扩展的计算资源产生了前所未有的需求。然而，中心化云提供商在定价和安全模型方面仍占据主导地位。在竞争日益激烈的人工智能领域，训练数据或模型权重的泄露可能带来显著优势，因此亟需一种既能保护静态、传输和使用中的数据，又能保持经济实惠和广泛可及性的计算基础设施。此外，现有的GPU集群产品（如8xH100s、8xH200s、8xB200s）造成了财务壁垒，限制了寻求安全高性能计算环境的组织、初创公司和独立研究人员的访问。本文介绍了一个去中心化的机密计算平台，利用英特尔信任域扩展（TDX）、英特尔信任权威（ITA）和NVIDIA机密计算（CC），构建一个由完全加密的机密虚拟机（CVM）组成的分布式生态系统。所提出的架构激励硬件提供商贡献支持英特尔TDX的计算资源。每个参与的提供商都被供应一个全新实例化、唯一加密的Ubuntu 24.04 CVM，在静态、传输和使用的所有阶段提供数据保护。通过将机密计算堆栈去中心化，并在独立运行的节点上利用机密计算，这项工作展示了一种可行的替代传统云基础设施的方案。所提出的系统提供了增强的安全保证、透明的成本结构和民主化的企业级安全计算能力访问，为下一代人工智能开发奠定了更开放、安全和公平的基础。

## Abstract
The rapid growth of artificial intelligence workloads has generated an unprecedented demand for secure and scalable compute resources. However, centralized cloud providers continue to dominate both pricing and security models. In an increasingly competitive AI landscape, where the compromise of training data or model weights can confer a significant advantage, there is a critical need for a computing infrastructure that safeguards data at rest, in transit, and in use, while remaining affordable and broadly accessible. Furthermore, existing GPU cluster offerings (e.g., 8xH100s, 8xH200s, 8xB200s) create financial barriers that limit access for organizations, startups, and independent researchers seeking secure, high-performance computing environments.   This paper introduces a decentralized, confidential computing platform that leverages Intel Trust Domain Extensions (TDX), Intel Trust Authority (ITA) and NVIDIA Confidential Computing (CC) to establish a distributed ecosystem of fully encrypted Confidential Virtual Machines (CVMs). The proposed architecture incentivizes hardware providers to contribute Intel TDX capable compute resources. Each participating provider is provisioned with a freshly instantiated, uniquely encrypted Ubuntu 24.04 CVM, providing data protection across all stages, at rest, in transit, and in use.   By decentralizing the confidential computing stack and leveraging confidential computing across independently operated nodes, this work demonstrates a viable alternative to traditional cloud-based infrastructures. The proposed system offers enhanced security assurances, transparent cost structures, and democratized access to enterprise-grade secure compute capabilities, paving the way for a more open, secure, and equitable foundation for next-generation AI development.

## 2. 方法论

### 2.1 核心理念
- 构建一个**去中心化机密计算平台**，利用 **Intel TDX、Intel Trust Authority (ITA) 和 NVIDIA Confidential Computing**，在硬件提供者贡献的节点上创建**完全加密的机密虚拟机（CVM）**，并通过**经济激励**吸引参与。
- 所有计算均在经硬件级证明的可信执行环境（TEE）中进行，**不信任主机、虚拟化管理程序或管理员**。

### 2.2 关键技术细节与流程

- **硬件层**：要求同时具有 **Intel TDX 兼容 CPU**（如第五/六代 Xeon）和 **NVIDIA CC GPU**（Hopper H100/H200 或 Blackwell B200），实现内存加密和受保护 PCIe（PPCIe）直通。
- **CVM 供应流程**：
  1. 从黄金 Ubuntu 24.04 镜像克隆，注入 NVIDIA 驱动和机密计算配置。
  2. 使用**随机生成的每虚拟机磁盘密钥**加密 QCOW2 镜像。
  3. 注入证明代理（Manifold Attestation Agent）和运行时服务。
  4. 预计算整个启动链的 TDX 测量值，连同磁盘密钥存储于 **Intel KBS**，密钥仅通过远程证明后释放。
  5. 交付启动脚本和 TDX 兼容的 OVMF 固件。
- **证明工作流**：
  - **早期启动证明**：initramfs 中的代理收集 TDX 测量寄存器，生成证明引用，提交至 KBS 并转发 ITA 验证。**只有测量值与预期匹配且环境可信时，才释放磁盘解密密钥**。启动失败则磁盘保持加密。
  - **持续证明**：每个区块间隔（约 72 分钟），CVM 执行多层证明：
    - 先进行 **NVIDIA nvtrust 证明**，确认 GPU 处于 CC 模式。
    - 将 GPU 证明报告和节点元数据嵌入 TDX 引用的用户数据字段，生成**统一证明**。
    - 验证者发出随机数，CVM 生成包含该随机数的新鲜引用，防止重放攻击。
    - 验证者通过 KBS 提交 ITA 验证，核对 TDX 测量、GPU 证明和 JWT 签名。通过则标记节点在线。
- **节点身份绑定**：首次证明成功后，KBS 将 CVM 绑定到**提供者的源 IP 地址**，防止磁盘复制、虚拟机迁移或证明重放。
- **去中心化编排**：通过 WireGuard 构建安全 overlay 网络，部署 Kubernetes 控制平面，CVM 作为工作节点，仅接纳持续通过证明的节点。Kubernetes 负责调度、故障恢复和自动扩缩容。
- **激励层**：验证者根据贡献的计算资源（如 GPU 类型、数量）计算权重并上链，通过网络代币实现**透明、去中心化的报酬分配**。

### 2.3 威胁模型与安全目标

- **对手能力**：完全物理控制主机、操作系统和 hypervisor，可启动/停止/快照/重放虚拟机，观测网络流量，但不能破解密码学原语或伪造硬件证明。
- **信任根**：Intel TDX / NVIDIA CC 硬件安全保证、ITA 证明验证、标准密码学假设。
- **安全目标**：工作负载保密性、执行完整性、环境真实性、不可迁移性、持续信任。
- **缓解措施**：全盘加密、IP 绑定、启动链测量验证、CC 保护 GPU 内存、非随机数挑战-响应抗重放等。
