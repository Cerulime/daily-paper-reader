## 摘要
微软的活动目录（Active Directory，AD）是一种目录服务，使 IT 管理员能够管理 Windows 域网络中的安全权限并控制访问。作为许多组织中的核心管理系统，AD 已成为攻击者的首要目标。尽管存在许多用于强化攻击图的解决方案，但这些努力在解决 AD 攻击图特有的几个关键实际挑战方面存在不足。首先，现有模型通常假设图是静态的，而实际的 AD 环境是高度动态的。其次，大多数提出的解决方案仅限于撤销漏洞（边移除）的防御措施，而更主动的防御机制在很大程度上未被研究。第三，由于并非所有补救措施都可实施，实用的端到端模型必须将系统管理员的反馈纳入优先级排序过程。本文旨在通过研究并提出若干基于博弈论和优化的决策模型来解决这些局限性。首先，我们提出了一种基于最小化最短路径数量和域管理员可达节点数量的蜜罐/诱饵放置模型。其次，在此模型基础上，我们引入了一种考虑 AD 图动态/时间特性的防御策略，其目标是找到部署诱饵的位置，以最大化最坏情况下的应急响应时间。第三，我们引入了一种自适应优先级排序模型，该模型将每个高风险攻击路径提交给 IT 管理员进行干预。最后，我们引入了一种端到端的自适应优先级排序模型，通过找到一种通用的自适应边移除策略，将系统管理员的决策推广到具有相似风险特征的边，从而最小化系统管理员的审批工作量。我们证明，所有贡献的模型背后的计算问题都是难以处理的。

## Abstract
Microsoft's Active Directory (AD) is a directory service that enables the IT admin to manage security permissions and control access within a Windows domain network. As a core management system in many of organisation, AD has become a primary target for adversaries. While many solutions for hardening attack graphs exist, these efforts fall short in addressing several key practical challenges specific to the AD attack graph. First, existing models often assume the graph is static, whereas a real-world AD environment is highly dynamic. Second, most proposed solutions are limited to the defensive measure of revoking vulnerabilities (edge removal), while more active defence mechanisms are largely unstudied. Third, because not all remediations are implementable, a practical end-to-end model must incorporate system admin feedback into the prioritisation process. This thesis aims to address these limitations by studying and proposing a number of game-theoretic and optimisation-based decision-making models. First, we propose a honeypot/decoy placement model based on the principle of minimising the number of shortest paths and the number of Domain Admin-reachable nodes. Second, building on this model, we introduce a defence strategy that considers the dynamic/temporal nature of the AD graph, where the objective is to find the location to deploy decoys that maximises the worst-case incident response time. Third, we introduce an adaptive prioritisation model that queries each high-risk attack path to the IT administrator for mediation. Finally, we introduce an end-to-end adaptive prioritisation model that minimises the approval effort of the system admin by finding a general adaptive edge-removal policy that generalises the system admin's decisions to edges with similar risk features. We show that the problems underlying all of the contributed models are computationally intractable.

### 2. 方法论
论文提出了四个核心贡献模型，分别对应四个主要章节：

*   **静态与动态网络中的蜜罐放置（第3章）**
    *   **核心思想**：将问题建模为攻防双方的Stackelberg博弈。防御方在攻击图上部署蜜罐，以最大化拦截攻击的概率。模型考虑了两种攻击者：无法发现蜜罐的“简单攻击者”和能完全规避蜜罐的“熟练攻击者”。
    *   **关键技术细节**：
        *   对静态图，构建了**混合整数规划（MIP）** 模型来求解最优蜜罐放置策略，以同时最小化两类攻击者的成功率。
        *   对动态图，提出**多图MIP（dyMIP(m)）** 模型，通过整合 `m` 个图快照来寻找一个对所有可能图状态鲁棒的解。
        *   为了扩展到大量图快照，设计了两种启发式算法：**投票法**（对多个dyMIP(m)结果进行多数投票）和**聚类法**（通过聚类选出代表性图快照再求解，显著提升效率）。

*   **优化时态网络中的网络响应时间（第4章）**
    *   **核心思想**：将动态AD图建模为**时态有向图**，边仅在特定时间窗口活跃。定义了一个新指标“响应时间”，即从攻击者触发第一个诱饵到其攻破核心资产（DA）的时长。防御者的目标是部署诱饵以最大化最坏情况下的响应时间。
    *   **关键技术细节**：
        *   证明该防御者优化问题是**NP-难的**。
        *   提出用**进化多样性优化（EDO）** 算法求解。为解决原始EDO算法计算慢、难收敛的问题，引入了两个关键技术：
            *   **基于Dijkstra的加速算法**：利用AD图大部分边为静态边的特性，加速时态最短路径的评估（适应度函数的计算）。
            *   **代理辅助与罚函数法**：设计一个轻量级的代理适应度函数，仅在重要的攻击路径子集上评估解，并对不可行解施加惩罚，从而引导算法快速找到可行且高质量的解。

*   **自适应向导移除跨层攻击路径（第5章）**
    *   **核心思想**：提出“自适应路径移除（APR）”模型，模拟安全向导与IT管理员交互式修复攻击路径的过程。向导在每轮提出一条攻击路径，管理员从中选择一条可移除的边。目标是最小化达到`源-目标`节点对不连通所需的期望查询次数。
    *   **关键技术细节**：
        *   将该问题建模为**马尔可夫决策过程（MDP）**。
        *   证明了该问题是**#P-难的**。
        *   提出了多种算法：
            *   **精确算法（OPT）**：基于动态规划。
            *   **近似算法（APP）**：利用自适应子模块性框架。
            *   **可扩展启发式算法（DPR）**：通过限制动态规划的向前看步数和候选动作（路径）空间，在可接受的时间内找到高质量解。

*   **基于强化学习的自适应连通性测试（第6章）**
    *   **核心思想**：提出“基于特征的自适应连通性测试（F-ACT）”模型。不同于传统模型中每条边有独立移除概率，该模型为每条边关联一个**安全特征向量**，并假设IT管理员的决策由一个未知的决策函数（根据特征判断边是否可移除）决定。向导的目标是学习一个自适应查询策略，将管理员对少数边的决策泛化到具有相似特征的边，从而在最少查询次数内确定 `源-目标` 的连通性。
    *   **关键技术细节**：
        *   证明了该问题的**#P-难**性。
        *   开发了**RL4FT算法**，专门解决标准RL在此任务中遇到的稀疏奖励和困难探索问题，包含三个创新组件：
            *   **策略无关的自改进机制**：能够从任意次优参考策略出发并迭代提升。
            *   **策略不变的奖励塑形函数**：提供了丰富且不改变最优策略的奖励信号。
            *   **定制的优先经验回放（PER）机制**：更有效地从高质量历史交互中学习。

*   **客观公平性**：对比广泛，涵盖了领域内先进的启发式、精确（理论上最优）方法、近似算法和强化学习基线。消融实验证明了提出组件的重要性。

### 6. 主要结论与发现
*   **计算复杂性**：论文所提出的所有核心防御优化问题（静态/动态蜜罐放置、最大化响应时间、自适应路径移除、特征自适应连通性测试）在计算上均为**难题（NP-难、#P-难或W[1]-难）**。
*   **MIP方法的有效性**：对于树状结构的AD图，MIP方法在静态场景下可高效求解，并能扩展到数十万节点的超大规模图。
*   **动态环境的重要性**：实验证明，基于静态图快照得到的最优防御策略，在动态环境中表现不佳。而通过考虑多个图快照（如dyMIP(m)）或时态建模的方法，能获得更鲁棒、更有效的防御方案。
*   **启发式与RL的实际应用价值**：
    *   所提出的集群/代理辅助等启发式方法在保持解质量的同时，**显著加速了计算**（如比原始EDO快108倍找到可行解）。
    *   精心设计的强化学习框架（DPR, RL4FT）能够有效超越传统算法和标准RL方法，在自适应与人机协同的复杂场景中表现出最佳性能。

### 7. 优点
*   **问题定义新颖且实际**：精准识别并解决了现有AD安全研究中的关键空白，即**动态性、主动防御和人机协同**这三大实际挑战。
*   **方法论全面深入**：整合了博弈论、组合优化、进化计算和深度学习/强化学习等多种计算方法，为每个问题提供了严格的理论证明（复杂性）和多样的算法方案。
*   **算法设计与理论结合紧密**：基于理论的算法设计（如自适应子模性用于近似保证、奖励塑形的策略不变性证明）展示了研究的深度。
*   **实验验证充分有力**：在合成和真实数据集上与丰富的基线方法进行全面对比，并辅以消融实验，结论可信度高。

### 8. 不足与局限
*   **真实环境部署验证**：尽管使用了部分真实数据，但整个加固模型框架并未在真实的、持续运行的企业AD环境中进行部署和长期闭环测试，其实用性和对管理员造成的额外负担仍是未知数。
*   **模型假设的简化**：
    *   攻击者模型（尤其是第3、4章）为主观假设，可能与真实攻击行为有差异。
    *   第5、6章中用户决策模型的设定（如Bradley-Terry模型、线性/单调决策函数）是对复杂人类行为的简化。
*   **计算复杂度的潜在瓶颈**：尽管提出了各种加速方法，但某些方法（如ILP修复算子）在特定大规模图上仍面临内存溢出（OOM）问题，限制了其通用性。
*   **功能独立**：四个核心贡献在论文中作为独立模块提出和验证，缺乏一个整合所有功能于一体（动态性 + 主动/被动防御 + 自适应人机协同）的端到端系统的案例研究。
