## 摘要
现代机器学习流水线严重依赖第三方库进行图编译与硬件加速。当前实践审计数据与模型制品或依赖文件完整性检查，而执行环境仍被隐性信任。这一盲区使活跃威胁成为可能，恶意运行时模块直接与实时训练和推理动态交互：利用这种交互，木马能够支持复杂目标，这些目标对于静态代码或二进制修改而言颇具挑战，进而实现标准数据与模型层面攻击无法达成的操纵。我们通过提出(A)iSpy来揭示这一漏洞，(A)iSpy是一种寄生于基础设施的木马，通过主动的观察与执行范式颠覆机器学习系统。在计算图内部运行时，(A)iSpy监控瞬态张量状态，以极低的开销进行定向、隐秘的操纵。为破坏机密性，该木马识别所有关键训练超参数，并通过模型权重或输出logits隐蔽地将其窃取。为破坏完整性，它充当梯度放大器：通过观察隐写触发器，它将原本弱效的数据投毒转化为有效的后门攻击，将成功率从近乎为零提升至100%。我们在附录中验证了辅助攻击，进一步展示了其贯穿机器学习生命周期的广泛可扩展性，这些攻击包括子群体标签翻转、可用性破坏以及推理阶段操纵。重要的是，(A)iSpy模块可轻松规避标准恶意软件扫描器，而关联的受污染输入及由此产生的受损模型则能绕过典型检查工具。我们通过在ONNX Runtime训练与推理引擎中的实现，展示了这一威胁的实用性。

## Abstract
Modern machine learning (ML) pipelines depend heavily on third party libraries for graph compilation and hardware acceleration. While current practices audit data and model artifacts or rely on file integrity checks, the execution environment remains implicitly trusted. This blind spot enables active threats where a malicious runtime module interacts directly with live training and inference dynamics: exploiting this interaction allows the Trojan to support complex objectives that are challenging for static code or binary modifications, achieving manipulations impossible for standard data and model level attacks. We expose this vulnerability by presenting (A)iSpy, a parasitic infrastructure Trojan that subverts ML systems through an active observe and execute paradigm. Operating within the computation graph, (A)iSpy monitors transient tensor states to perform targeted, stealthy manipulations with negligible overhead. To violate confidentiality, the Trojan identifies all critical training hyperparameters and covertly exfiltrates them via model weights or output logits. To break integrity, it acts as a gradient amplifier: by observing steganographic triggers, it transforms otherwise weak data poisoning into effective backdoor attacks, increasing success rates from near zero to 100%. We further demonstrate broad extensibility across the machine learning lifecycle by validating auxiliary attacks in the appendix, including subpopulation label flipping, availability disruptions, and inference stage manipulations. Importantly, the (A)iSpy module easily evades standard malware scanners, while the associated poisoned inputs and resulting compromised models bypass typical inspection tools. We demonstrate the practicality of this threat with an implementation in the ONNX Runtime training and inference engines.

*   **核心思想：“观察-执行”范式**：木马（名为 `(A)iSpy`）注册为合法的图优化器或执行提供器，从而获得对权重、梯度、激活值等张量内存的直接访问权限。它持续运行一个控制循环：先观察当前张量状态，然后根据观察结果执行恶意操作。
*   **关键技术细节与攻击实现**：
    *   **后门放大攻击（破坏完整性）**：
        1.  **协调者（外部）**：在少量样本上叠加一个隐写载体（伪随机向量）和一个后门触发器。
        2.  **中间件（`(A)iSpy`）**：
            *   **观察**：使用匹配滤波器实时检测输入中是否包含隐写载体，以此识别被污染的样本。
            *   **执行**：对识别出的样本，先执行载体消毒（移除载体），然后通过**批量重放**（将一个携带后门的样本在多个后续批次中重复出现）和**梯度缩放**（放大该样本产生的梯度信号）的组合，将极低比例的投毒攻击放大为高效的后门攻击。
        3.  **效果**：即使训练集中只有一个投毒样本（例如, 2% 投毒率），也能将后门攻击成功率从近乎 0% 提升至逼近 100%。

### 4. 资源与算力

*   **硬件配置**：后门攻击使用 NVIDIA RTX A6000 GPU，无差别攻击使用 NVIDIA A100 GPU。超参数暴力搜索成本预估实验使用了两个 NVIDIA RTX 6000 Ada Generation GPU。
*   **训练时长**：文中未明确列出所有攻击的总训练时长，但指出超参数窃取攻击本身在识别并嵌入有效载荷后，整体训练开销可忽略不计。文中还对暴力搜索最优超参数的成本进行了预估，例如，LLaMA-2-7B 的完整搜索预计耗时 **485 GPU 小时**（约 20 天），而 `(A)iSpy` 可在不到 1 秒内完成窃取，凸显了攻击的经济性。

### 5. 实验数量与充分性

*   **实验数量**：论文进行了大量的实验。后门攻击在多个数据集、模型架构和投毒比例下进行了测试。超参数窃取在 **19种 模型-数据集组合**下进行了验证。针对无差别攻击和子群体攻击，也在多个模型和数据集上进行了评估。此外，还设置了消融研究（例如，分析重放和梯度缩放的联合效用）和鲁棒性测试（抗微调、剪枝）。
*   **充分性与公平性**：实验设计较为充分和客观。它不仅包含了与多种基线攻击和先进防御技术的比较，还在白盒和黑盒等不同威胁假设下验证了攻击的有效性和隐蔽性。实验覆盖了计算机视觉和自然语言处理两大领域，且评估指标（如攻击成功率、准确率下降、比特错误率）选择合理，能全面反映攻击的性能。

### 6. 论文的主要结论与发现

*   **新型威胁模型被证实可行**：ML运行时中间件的特权地位构成了一个严重的安全盲区，`(A)iSpy` 能够利用它实现强大的攻击。
*   **攻击高效且隐蔽**：`(A)iSpy` 能将数据投毒攻击的效率提升数个量级，同时绕过几乎所有针对数据、模型和二进制文件的静态检测和扫描，包括主流恶意软件扫描器。
*   **机密性与完整性被双双突破**：论文成功演示了如何从模型权重或行为中无损地窃取宝贵的训练配方，以及如何将无效的后门攻击放大至完全成功。
*   **攻击面广泛**：统一的“观察-执行”框架能够支撑从完整性、机密性到可用性的多种攻击目标，展示了其极大的通用性。
*   **防御缺失**：目前的防御体系在整个 ML 堆栈中留下真空地带，需要将运行时环境视为潜在的不信任代码，并引入包签名、构建可重现性等技术来加固供应链安全。

### 7. 优点

*   **原创性与影响力强**：首次系统性地定义并实操了以 ML 运行时中间件为核心的新型威胁模型，安全意义重大。
*   **技术方法巧妙**：利用扩频通信等经典技术解决了攻击中最棘手的隐蔽性和鲁棒性问题，如隐写载体的检测和有效载荷的嵌入。
*   **实验扎实且全面**：不仅展示了攻击的威力，还深入评估了其隐蔽性，并对比了大量基线方法和防御手段，论证具有很强的说服力。
*   **工程实践性强**：攻击在工业级 ML 框架（ONNX Runtime, TensorRT）中实现，证明了威胁的真实性不局限于学术模拟。
*   **结构清晰**：将攻击抽象为观察、执行等几个基本原语的设计，使得整个工作框架清晰且易于理解和扩展。

### 8. 不足与局限

*   **白盒假设的依赖**：超参数窃取和后门放大的某些环节依赖攻击者与中间件共享密钥或码本，这构成了一个可能被防护的侧信道。
*   **防御方先决知识**：论文虽然证明了攻击能规避现有防御，但并未深入探讨如果防御者意识到这种威胁模型，并专门设计针对运行时内存审计或行为的动态防御系统时，攻击将如何应对。
*   **后门触发的选择性**：后门放大的有效性依赖于攻击者能够将极少量的投毒样本送入训练集，这在现实世界中虽然能力普遍，但仍是攻击链条上的一个外部依赖环节。
*   **附加攻击的深度**：相对于后门和超参数窃取，诸如子群体操纵等辅助攻击在实验设计和分析深度上略显薄弱。
*   **黑盒超参数窃取的鲁棒性**：行为后门本身对持续的清洗性微调可能更为脆弱，这个局限性在论文中也有提及。
