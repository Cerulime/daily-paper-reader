## 摘要
远程证明是一种轻量级安全原语，用于检测物联网设备上的软件危害。传统远程证明方案要求进行原子性、不可中断的内存测量，这使其难以与实时工作负载一同部署。SMARM 通过以秘密的乱序块顺序测量内存来解决这一限制，将不可中断周期缩短到单个块测量的持续时间。然而，SMARM 最初是为基于微内核的系统设计的，尚未在基于实时操作系统的实时环境中进行研究。在本工作中，我们首次在基于实时操作系统的实时环境中对 SMARM 进行系统性研究。我们在运行 FreeRTOS 和 Zephyr 的商用 ARM TrustZone-M 硬件上实现了 SMARM，并引入频率准确性比率（FAR）来量化不同工作负载下远程证明与实时执行的共存程度。我们的评估显示，SMARM 的实时兼容性对块大小高度敏感：大块会显著降低实时可用性，而小块则会导致大量安全存储开销，限制了在内存受限设备上的可部署性。为了解决这一限制，我们提出了 SMARM+，这是一个增强型 SMARM 变体族，包括 SMARM+PRNG 和 SMARM+FPE。它们旨在减少安全存储需求，同时保持 SMARM 的安全保证和实时行为。我们的评估突出了安全存储减少、证明运行时和能量开销之间的权衡，并为不同部署场景下选择 SMARM、SMARM+PRNG 和 SMARM+FPE 提供了指导。

## Abstract
Remote attestation (RA) is a lightweight security primitive for detecting software compromise on IoT devices. Traditional RA schemes require atomic, non-interruptible memory measurements, making them difficult to deploy alongside real-time workloads. SMARM addresses this limitation by measuring memory in a secret, shuffled block order, reducing the non-interruptibility period to the duration of a single block measurement. However, SMARM was originally designed for microkernel-based systems and has not been studied in RTOS-driven real-time environments.   In this work, we present the first systematic study of SMARM in real-time RTOS-based setups. We implement SMARM on commodity ARM TrustZone-M hardware running FreeRTOS and Zephyr, and introduce the Frequency Accuracy Ratio (FAR) to quantify the extent to which attestation can coexist with real-time execution under varying workloads. Our evaluation shows that SMARM's real-time compatibility is highly sensitive to block size: large blocks significantly degrade real-time availability, while small blocks incur substantial secure-storage overhead, limiting deployability on memory-constrained devices.   To address this limitation, we propose SMARM+, a family of enhanced SMARM variants consisting of SMARM+PRNG and SMARM+FPE. They are designed to reduce secure-storage requirements while preserving SMARM's security guarantees and real-time behavior. Our evaluation highlights the trade-off between secure-storage reduction, attestation runtime, and energy overhead, and provides guidance on selecting among SMARM, SMARM+PRNG, and SMARM+FPE for different deployment settings.

## 1. 论文的核心问题与整体含义

*   **研究背景：** 远程证明（RA）作为物联网设备检测软件篡改的轻量级安全机制，传统方案要求对内存进行原子、不可中断的哈希测量。这与实时系统（如基于 FreeRTOS、Zephyr 的设备）强冲突，因为关闭中断时间过长会破坏任务的实时性。
*   **核心难题：** 现有方法 SMARM 虽通过“乱序分块测量”将不可中断周期缩短至单个块的测量时长，但其设计依赖微内核（seL4），未曾在主流实时操作系统（RTOS）环境下部署与验证。其根本矛盾在于：块大小若太小，虽能保证实时可用性，但存储乱序排列所需的安全存储开销极大（\(O(n \log n)\) 位），不利于资源受限设备；块太大则实时性受损。
*   **本文目标：** 在真实 RTOS + TrustZone‑M 硬件环境中，首次系统分析 SMARM 对实时任务的实际干扰，并设计增强变体以减少安全存储需求，使乱序证明能够真正部署在实时 IoT 设备上。

## 2. 方法论：核心思想与技术细节

*   **SMARM on RTOS 实现：**
    *   利用 ARM TrustZone‑M 的硬件隔离取代微内核：将安全敏感逻辑（SMARM 服务）置于安全世界，非安全世界运行普通的 RTOS 和实时任务。
    *   安全世界通过 CPSID 指令在测量每一个块时短暂关中断，保证块级原子性；非安全世界中的 SMARM 包装任务以最低优先级运行，允许实时任务随时抢占。
    *   安全需求（S1‑S3）：（S1）受控执行，（S2）证明密钥保密，（S3）测量顺序私密。全部通过 TrustZone‑M 的硬件强制隔离和 NSC 入口保护实现。

*   **SMARM+ 变体（减少安全存储）：**
    *   **SMARM+PRNG：** 将存储需求从 \(O(n\log n)\) 降至 \(O(n)\) 位。不再存储完整乱序排列，而是维护一个大小为 \(n\) 的位图 `used`（标记已测量块）。每一轮通过伪随机生成器产生随机数 \(r\)（范围是剩余块数），然后扫描位图找到第 \(r\) 个空闲块进行测量。
    *   **SMARM+FPE：** 将安全存储降至 \(O(1)\)。利用格式保持加密（FPE）的 FFX 构造（底层为 Speck 轻量级分组密码），将迭代序号 \(i\) 加密为块索引 \(idx\)。由于加密是双射，自然产生不重复的伪随机排列，无需存储任何排列状态。

*   **实时干扰度量：** 提出频率准确性比率（FAR），定义为有证明时的实时任务执行频率与基线频率（无不可中断测量）之比。FAR=1.0 表示证明对实时任务无干扰。

## 6. 主要结论与发现

*   **块大小是关键：** 在 \(B \le 1024\) B 时，FAR 可维持在接近 1.0，实时任务几乎不受影响；\(B \ge 2048\) B 则会导致 FAR 大幅下降至 0.5‑0.3，证明严重破坏实时性。
*   **SMARM+ 可大幅降低安全存储：**
    *   SMARM+PRNG 在 \(B=1024\) B 时将存储减少 9 倍，运行时间仅增加 7%，能耗增加 5%。
    *   SMARM+FPE 存储恒为 16 B，存储减少达 36 倍，但运行时间增加 48%，能耗增加 52%。
*   **部署建议：** 若安全存储专用，用原始 SMARM；需节省部分安全 RAM 时，用 SMARM+PRNG；安全世界负载极繁重时，使用 SMARM+FPE。
*   RTOS 类别（FreeRTOS vs Zephyr）对 FAR 影响甚微，主要瓶颈来自块测量的原子时间。

## 7. 优点

*   **填补空白：** 首次将 SMARM 从微内核移植到广泛使用的 RTOS+TrustZone‑M 平台，并系统评估其对实时任务的影响。

*   **实用变体：** SMARM+ 提供了清晰的存储‑性能权衡方案，对指导真实部署有直接价值。
