## 摘要
分支预测器提高了现代处理器中的指令级并行性，通常使用饱和计数器建模。然而，经典的饱和计数器是确定性的，因此容易受到侧信道攻击：攻击者可以操纵计数器状态并推断受害进程的分支方向。概率饱和计数器（PSC）已被提出通过随机化计数器更新来缓解这种泄漏，但现有的评估主要是经验性的。在本文中，我们基于差分隐私（DP）给出形式化分析：我们将PSC和相应的Prime+Probe攻击策略建模为概率摩尔机，推导出最优攻击策略，并通过DP量化攻击者的区分能力。我们的DP保证适用于Prime+Probe观察模型下的PSC原语；在重复或自适应攻击下，完整分支预测器的端到端安全性是未来工作的重要方向。然后，我们为增强型PSC合成参数，使其满足目标纯DP保证。为了评估实用性，我们推导了稳态误预测率，并在基准程序上验证了理论预测。与确定性和现有概率饱和计数器相比，合成的PSC在保持竞争性预测性能的同时提供了正式的安全保证。

## Abstract
Branch predictors improve instruction-level parallelism in modern processors and are commonly modeled using saturating counters. However, classical saturating counters are deterministic and thus vulnerable to side-channel attacks: an attacker can manipulate the counter state and infer the branch direction of a victim process. Probabilistic saturating counters (PSCs) have been proposed to mitigate this leakage by randomizing counter updates, but existing evaluations are mainly empirical. In this paper, we give a formal analysis based on differential privacy (DP): we model PSCs and the corresponding Prime+Probe attack strategies as probabilistic Moore machines, derive optimal attack strategies, and quantify the attacker's distinguishing power through DP. Our DP guarantee applies to the PSC primitive under the Prime+Probe observation model; end-to-end security for a full branch predictor under repeated or adaptive attacks is an important direction for future work. We then synthesize parameters for an enhanced PSC that satisfies a target pure DP guarantee. To evaluate utility, we derive the stationary misprediction rate and validate the theoretical predictions on benchmark programs. Compared to deterministic and existing probabilistic saturating counters, the synthesized PSCs provide formal security guarantees while preserving competitive prediction performance.

### 2. 论文提出的方法论

- **核心思想**：将防御问题转化为差分隐私机制设计问题。把受害者的单次分支方向视为敏感数据（相邻数据集仅相差这一位），把 Prime+Probe 攻击算法（FindCutOffPoint）的输出 c（截止点）视为机制输出，用 DP 定义攻击者区分两种分支方向的难度。
- **形式化建模**：
  - 将经典 SC、现有 PSC、增强 PSC 均建模为概率 Moore 机（Probabilistic Moore Machine）：状态集 S、初始分布、转移概率矩阵 M、输出函数 O。
  - 分别构建受害分支为 Taken（v=T）和 Not-Taken（v=NT）时的攻击过程 Moore 机（图 3 与图 5），通过矩阵幂运算计算输出概率：
    - `Pr[out=c | v=T] = 1^T_ST M_T^{c+1} 1_SN`
    - `Pr[out=c | v=NT] = 1^T_ST M_NT^{c+1} 1_SN`
- **最优攻击策略**：若 `c > 1/m`，则推断 v=T；否则推断 v=NT。并通过贝叶斯定理计算后验概率，攻击者选取后验较大的方向。该策略揭示了现有 PSC 的关键弱点：观测到 c=1 时，攻击必然成功（因为 v=T 时从 ST 到 SN 至少需要两步）。
- **增强型 PSC 设计（核心创新）**：
  - 新增防御参数 p ∈ (0,1)，仅在强状态（ST 和 SN）注入额外随机化：例如从 ST 输入 T 时，以概率 mp 转移到 WT（而非确定性自环）；从 ST 输入 NT 时，以概率 m(1-p) 转移到 WT、以概率 1-m+mp 留在 ST（详见论文图 4）。
  - 理论推导：**Thm. 1** 给出纯 DP 保证——若 p ≥ 1/2，则增强 PSC 满足 `(ln(p/(1-p)), 0)`-DP；否则满足 `(ln((1-p)/p), 0)`-DP。值得注意的是，该隐私保证与 m 无关（m 在两类模型中为公共因子，可在概率比中约去）。
  - **Prop. 1**：对于任意目标隐私预算 ε > 0，最优防御参数为 `p* = 1/(1+e^ε)`（取小于 0.5 的根），在满足相同 DP 保证的所有参数中误预测率最低。
- **性能分析**：用马尔可夫链平稳分布计算误预测率 r。设 t 为分支 Taken 概率，s=1-t，q=1-p，得到解析解：
  `r = [ts(qt+ps)(1+qs+pt) + ts(qs+pt)(1+qt+ps)] / [t(qt+ps)(1+qs+pt) + s(qs+pt)(1+qt+ps)]`
  并证明 r 仅依赖于 p 和 t，与 m 无关。
- **与随机响应（RR）机制对比**：论文比较了两种 DP 机制——RR 在每一步翻转分支输入，而增强 PSC 仅在强状态随机化，后者在相同隐私预算下误预测率更低。
- **一般化**：将方法扩展到任意 k 位 PSC。Thm. 2 证明增强型 k 位 PSC 的 DP 保证与 2 位情形相同；Thm. 3 证明其误预测率与 m 无关。

### 6. 论文的主要结论与发现

- **现有 PSC 存在固有漏洞**：基于概率 Moore 机分析和最优攻击策略推导，现有 PSC（仅参数 m）在 c=1 时攻击者必然成功，因此无法满足任何 δ<1 的 (ε,δ)-DP 保证；标准 k 位 PSC 的攻击判别条件退化为 `c ≷ (2^{k-1}-1)/m`，攻击可高置信度成功。
- **增强 PSC 可实现纯 DP**：在强状态引入防御参数 p 后，增强 PSC 对任意 ε>0 可满足 `(ε,0)`-DP，且保证与更新概率 m 无关。
- **最优参数存在闭式解**：`p* = 1/(1+e^ε)` 在满足给定隐私预算的所有参数中最小化稳态误预测率。
- **性能影响可控**：实验表明，以 (ln9,0)-DP 为目标（p=0.1, m=0.5），在 SPEC 2017 上平均归一化性能开销仅 1.8%（除 cam4 离群点）。部分随机化配置（如 (0.8,0.4)）甚至优于确定性基线（xalancbmk 提升 4.1%），印证了随机化可避免预测器陷入次优状态的观察。
- **优于随机响应机制**：在相同 ε 下，增强 PSC 的误预测率始终低于 RR 机制，偏斜分支和高隐私要求下优势尤其显著（最高降低 78%）。
