## 摘要
尽管机器学习模型取得了显著成功，尤其在视觉应用中，但它们却极易受到一系列安全威胁。攻击形势中的一个关键因素是白盒与黑盒威胁模型之间的区别，因为后者在模型信息访问受限时会带来限制攻击有效性的挑战。因此，使用可信执行环境（TEE）通过保护模型的机密性和执行完整性来增强机器学习应用的安全性，有效地将执行环境从威胁模型光谱的白盒一侧转移到黑盒一侧。虽然为大型视觉模型（如视觉Transformer，ViT）采用TEE对于增强安全性和隐私性至关重要，但必须解决与内存限制和计算延迟增加相关的重大挑战，尤其是在安全性和隐私性至上的时间敏感型边缘应用中。本工作的目标是使大型视觉模型能够完全托管在TEE内，在保持性能的同时，为时间敏感的边缘视觉应用实现GPU级别的推理延迟。为此，我们提出了TEE-X，一个TEE感知的加速框架，它引入了敏感度感知的模块化技术，并在TEE推理中实现向量化。该设计在面向Arm TrustZone的OP-TEE上进行了验证，并配置为在NVIDIA Jetson AGX Xavier上优化性能，以使用ViT模型实现高效的边缘视觉应用。研究结果表明，TEE-X提供了一种有效的TEE感知加速框架，在确保视觉模型快速、安全边缘推理的同时，实现了最小的精度-延迟权衡。

## Abstract
Despite their remarkable success, machine learning models, particularly in vision applications, are alarmingly vulnerable to a range of security threats. One key factor in the attack landscape is the distinction between white-box and black-box threat models, as the latter poses challenges that limit attack effectiveness when access to model information is limited. As a result, using Trusted Execution Environments (TEEs) enhances security for machine learning applications by protecting model confidentiality and execution integrity, effectively shifting the execution environment from the white-box to the black-box side of the threat model spectrum. While adopting TEEs for large vision models, e.g., Vision Transformers (ViTs), is crucial for enhancing security and privacy, significant challenges related to memory constraints and increased computational latency must be addressed, especially in time-sensitive edge applications where safety and privacy are paramount. The objective of this work is to enable large vision models to be fully hosted within TEEs, achieving GPU-level inference latency for time-sensitive edge vision applications while maintaining performance. To this end, we propose TEE-X, a TEE-aware acceleration framework that introduces a sensitivity-aware modularization technique and enables vectorization in TEE inference. This design is validated on OP-TEE for Arm TrustZone, configured to optimize performance on the NVIDIA Jetson AGX Xavier for efficient edge vision applications using ViT models. The findings reveal that TEE-X delivers an effective TEE-aware acceleration framework that achieves minimal accuracy-latency trade-offs while ensuring fast and secure edge inference for vision models.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **安全威胁背景**：机器学习模型（尤其是视觉应用）面临多种安全攻击，包括内存故障注入（如 Rowhammer、位翻转攻击）、侧信道攻击和对抗样本攻击。这些攻击根据威胁模型可分为白盒攻击（攻击者对模型架构、参数、梯度有完全访问权）和黑盒攻击（攻击者仅能通过输入输出查询交互）。
- **核心问题**：白盒攻击下模型极易被攻破，而TEE（可信执行环境）可以将模型执行环境从白盒一侧推向黑盒一侧，从而显著增强安全性。然而，TEE存在两个关键瓶颈：
  - **TEE内存容量有限**，大型视觉模型（如ViT）难以完整放入TEE中。
  - **TEE内计算延迟高**，相较于GPU原生执行存在显著性能开销。
  - 这些瓶颈在**时间敏感的边缘应用**（如自动驾驶、医疗保健）中尤为严峻。
- **现有方案不足**：已有方法多采用模型分区（部分层在TEE内执行）或操作感知执行（敏感操作放在TEE内），但这些方法：
  - 仍无法达到GPU级别的推理速度；
  - 模型部分暴露在不可信区域，给攻击者留有可利用的信息。
- **本文目标**：设计一种加速方法，实现**整个大型视觉模型完全托管在TEE内部**，同时达到与GPU相当的推理延迟，并保持模型性能（准确率）。

## 2. 论文提出的方法论

### 2.1 核心思想

TEE-X框架由两个核心组件构成：**模块化（Modularization）** 与**向量化（Vectorization）**。设计遵循两个原则：①严格满足TEE的内存与延迟预算；②在预算约束下保持模型准确性。

### 2.2 模块化（Modularization）——TEE感知的计算预算分配

模块化包括三个步骤：

- **步骤一：敏感性感知的模块选择**
  - 对预训练ViT模型中每一层计算敏感性分数S_i。
  - **敏感性度量方法**：对第i层注入高斯噪声扰动：Δwᵢ = ε∥wᵢ∥_F · gᵢ/∥gᵢ∥_F，其中gᵢ ~ N(0, I)。然后计算扰动前后的准确率差：Sᵢ = A_w − A_ewᵢ。Sᵢ越大表示该层越敏感。
  - 将敏感性相近的层划分为同一模块（Module），共划分为K个模块{G₁, G₂, ..., G_K}。
- **步骤二：分配计算预算到每个模块**
  - 对每个模块中的每一层，将其权重矩阵wᵢ分解为Aᵢ ∈ R^{nᵢ×hᵢ}和Bᵢ ∈ R^{hᵢ×nₒ}，其中hᵢ控制计算量。
  - 在总计算预算C（由TEE报告的与GPU性能对齐的预算）约束下，采用**敏感性引导的规则分配**：
    - h_k = (Σ_{∀j∈G_k} S_j / Σ_{∀i∈L} Sᵢ) · (C / n_gk)
    - 即为敏感性更高的模块分配更大的计算预算，敏感性的模块分配更少的预算。
  - 计算预算C的确定：hᵢ = nᵢnₒ/(nᵢ+nₒ) · (T_GPU/T_TEE)，使得TEE推理时间与GPU相当。
- **步骤三：实现预算分配（训练变换网络）**
  - 为每个模块学习变换网络T_k（将wᵢ映射为Aᵢ）和线性变换B_k（使得wᵢ ≈ Aᵢ × Bᵢ）。
  - **训练目标**：联合优化所有模块的T_k和B_k，使用三种损失：
    - 交叉熵损失L_CE：保持任务准确率；
    - 知识蒸馏损失L_KD：保持与原模型的输出行为一致；
    - MSE损失L_MSE：对齐每层的输出。
  - 总损失：L_total = L_CE + λ_KD·L_KD + λ_MSE·L_MSE。
  - 推理时仅存储变换后的权重{A_k}和对应的线性变换{B_k}，大幅减少内存占用。

### 2.3 向量化（Vectorization）——TEE内的SIMD加速支持

- 利用**Arm Neon SIMD指令**（128位宽寄存器）在TEE内实现GPU级的并行计算。
- **FMA（Fused Multiply-Accumulate）操作**：使用`vfmaq_f32`指令同时处理4个float32值。
- **缓存友好访问**：通过循环展开（unroll），使用4个独立的累加器寄存器打破依赖链，每次内循环推进16列，提高指令流水线利用率。
- **共享内存机制**：权重和输入通过主机分配的共享内存传递给TA（Trusted Application），中间张量始终保存在安全内存中，最小化主机与TA之间的通信。
- 该设计使TEE-X在单批推理中可与GPU性能匹配。

## 6. 论文的主要结论与发现

1. **TEE-X实现了在TEE内部完整运行大型视觉模型的目标**，无需将模型分区或卸载到不可信环境，从而提供了更强的安全保障（从白盒走向黑盒攻击谱）。

2. **性能接近GPU**：在C=0.5时，DeiT-Small在CIFAR-10上的推理时间为1082.67ms，与GPU基线（1022.35ms）基本持平（1.42×的层平均时间差异）；在C=0.2时，TEE-X（957.13ms）甚至略快于GPU基线。

3. **精度损失可忽略**：在C=0.5和C=0.4下，准确率下降不到1%（96.48%和96.40% vs. 97.29%）；即使在激进的C=0.2下（模型压缩47×），精度下降仅2.65%。

4. **模型规模大幅缩减**：在C=0.2下，DeiT-Small模型从82.66MB压缩至1.75MB（约47×）；DeiT-Base从327.33MB压缩至5.80MB（约56×）。

5. **优于现有TEE框架和传统加速方法**：
   - 相对模型分区（1463.80ms）和操作感知执行（3127.73ms），TEE-X（1082.67ms）延迟更低。
   - 相对于剪枝（精度60.51%）和2-bit量化（精度71.90%），TEE-X在ImageNet上达到76.44%的精度，且支持TEE环境。

6. **消融实验表明模块化和向量化均不可或缺**：去掉模块化延迟增加80%，去掉向量化延迟增加77%。

7. **敏感性引导的预算分配优于均匀分配**：在C=0.2下，TEE-X（94.64%）比均匀分配（91.27%）精度提升3.37个百分点。

## 7. 优点

- **创新性强**：首次提出“敏感性感知模块化+向量化”的TEE-aware加速方案，与以往的分区/卸载策略有本质区别，实现了**完全在TEE内执行整个模型**。
- **安全性显著提升**：模型完全驻留在TEE内，攻击者无法获取中间层的权重或输出，将威胁模型推至黑盒端。
- **实际应用导向**：在真实边缘设备（Jetson AGX Xavier）上验证，而非模拟环境，具有工程实践价值。
- **精度-延迟权衡出色**：通过敏感性引导的预算分配，在保持精度的同时实现压缩，优于传统的均匀压缩方法。
- **消融实验详尽**：不仅评估了各组件对性能的贡献，还对比了不同的预算分配策略，论证充分。
- **向量化实现具有代表性**：使用Arm Neon SIMD+FMA+循环展开的组合优化思路，对TEE内CPU加速有通用参考价值。

- **硬件普适性**：仅在单一硬件平台（Jetson AGX Xavier + OP-TEE）上验证，未覆盖Intel SGX、AMD SEV等其他TEE技术。

- **训练开销未报告**：虽然提到训练使用单张A6000 GPU，但未报告训练所需的总时间，这对实际部署的可复现性是信息缺口。

- **潜在偏差风险**：与剪枝和量化方法的对比可能不完全公平——竞争方法未在相同的变换训练框架下重新训练或调优，且论文使用的量化配置（4-bit QAT + 首尾8-bit）属于定制化优化，对比方法未必采用了同等优化水平。
