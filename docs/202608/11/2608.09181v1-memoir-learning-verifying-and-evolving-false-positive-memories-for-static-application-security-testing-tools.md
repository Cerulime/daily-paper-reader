## 摘要
静态应用安全测试（SAST）工具已成为现代安全软件开发中不可或缺的一部分。然而，这些工具常常生成错误阳性（FP）警报，导致大量人工检查成本，并降低开发者的信任。现有的FP缩减方法仍面临两个主要挑战。首先，不同SAST工具和漏洞类别之间的巨大差异使得这些方法难以学习历史错误阳性中的重复模式。此外，这些方法所使用的知识在很大程度上是静态的，无法随着新验证案例的积累而更新。为应对这些挑战，我们提出了Memoir，一种通过将历史FP警报转化为可复用的语义记忆来识别错误阳性的记忆驱动框架。它包含两个关键模块。首先，历史语义记忆构建通过LLM引导的注释、模式聚类和记忆综合，将历史FP警报转化为结构化的语义记忆，以捕获可复用的行为模式。此外，记忆驱动的识别与演化在做出最终预测之前，检索相关记忆并针对分类一致性和安全不变量进行语义验证。随后，它将经过验证的预测回填到记忆库中，使知识库能够随着新案例的积累而演化。我们在CWE-Bench-Java上评估了Memoir，以证明其在现实世界安全分析中的有效性。具体而言，Memoir达到了99.43%的F1分数，召回率为98.88%，精确率为100%，始终优于其他基线。此外，对一家顶级IT公司生产软件系统的工业案例研究表明，学习到的记忆库无需重新训练即可有效推广到不同的SAST工具。

## Abstract
Static Application Security Testing (SAST) tools have become indispensable in modern secure software devel- opment. However, these tools often generate false-positive (FP) alerts, imposing substantial manual inspection costs and reducing the trust from developers. Existing FP reduction methods still face two primary challenges. First, the large differences among SAST tools and vulnerability categories make it difficult for these methods to learn recurring patterns in historical false positives. Moreover, the knowledge used by these methods are largely static and cannot be updated as newly validated cases accumulate. To address these challenges, we propose Memoir, a memory- driven framework for identifying false positives by transform- ing historical FP alerts into reusable semantic memories. It consists of two key modules. First, historical semantic memory construction converts historical FP alerts into structured semantic memories through LLM-guided annotation, pattern clustering, and memory synthesis to capture reusable behavioral patterns. Moreover, memory-driven identification and evolution retrieves relevant memories and performs semantic verification against taxonomy consistency and security invariants before making the final prediction. It then incorporates verified predictions back into the memory repository, allowing the knowledge base to evolve as new cases accumulate. We evaluate Memoir on CWE- Bench-Java to demonstrate its effectiveness in real-world security analysis. Specifically, Memoir achieves an F1-score of 99.43% with a Recall of 98.88% and perfect Precision, consistently outperforming other baselines. Furthermore, an industrial case study on production software systems from a top IT company shows that the learned memory base generalizes effectively across different SAST tools without retraining.

### 1. 核心问题与整体含义（研究动机与背景）

- 静态应用安全测试（SAST）工具（如 CodeQL、Checkmarx、Fortify）在现代软件开发中被广泛用于早期发现漏洞，但其产生的错误阳性（False Positive, FP）警报数量庞大，经常超过报告的半数以上，导致开发者“警报疲劳”，并降低对工具本身的信任。
- 在公开基准 CWE-Bench-Java 上，作者用 CodeQL 对 120 个 Java 项目检测出 865 条警报，其中 95.66% 被人工验证为误报，凸显了误报问题的严重性。
- 现有误报削减方法存在两大挑战：
  1. **难以学习复杂 FP 语义**：误报往往不是孤立事件，而是跨项目、跨工具、跨 CWE 类别反复出现的语义模式（如白名单映射、框架自动转义、预编译语句绑定、路径规范化等）。现有方法难以从历史误报中抽象出可复用的规律。
  2. **知识无法持续更新**：已有方法依赖的知识库大多是静态的，无法随着代码库演化、框架升级和新漏洞类型出现而增长，导致性能随时间衰减。
- 为此，论文提出 **Memoir**——一种记忆驱动的误报识别框架，将历史误报转化为“可复用、可验证、可演化”的语义记忆，从而同时解决上述两个问题，提升 SAST 工具的实际可用性。

### 2. 方法论：核心思想、关键技术细节与流程

**核心思想**  
将 SAST 误报识别从“逐条独立推理”重构为“可复用语义记忆学习”问题。Memoir 不再直接记住历史警报实例，而是将多个相似案例抽象为结构化、泛化的“误报记忆”，并在新警报到来时检索、验证和复用这些记忆。

**整体框架包含三个阶段**（即“学习—验证—演化”）：

- **阶段 I：误报记忆构建（Learning）**
  - 输入：历史 CodeQL 警报与人工标注标签（FP/TP）。
  - 步骤：
    1. **FP 轨迹提取**：提取标准化的污点传播路径、CWE 信息、source/sink 上下文等。
    2. **LLM 引导语义标注**：使用 LLM 标注误报的类别、根因、安全不变量、污点阻断机制。
    3. **模式聚类**：基于语义特征（如不变量、污点阻断器）而非表面文本相似度进行聚类，将相同语义模式的案例归为同一簇。
    4. **记忆综合**：将每个簇综合成一条广义记忆条目，包含六个要素：
       - T：分类学信息（taxonomy）
       - I：安全不变量（security invariants）
       - B：污点阻断器（taint breakers）
       - K：检索键（retrieval keys）
       - V：验证规则（verification rules）
       - E：代表性示例（representative examples）
  - 记忆库分为三个层级：**Taxonomy Memory**（粗粒度分类）、**Pattern Memory**（可复用 FP 知识）、**Evolution Memory**（历史验证反馈与使用统计）。

- **阶段 II：记忆驱动的误报识别（Verifying）**
  - 对新警报执行分层检索：
    - L1：按 CWE、规则类型、语义标签进行 taxonomy 级过滤，剔除无关记忆。
    - L2：基于安全不变量相似度、污点阻断器一致性、检索键匹配对候选记忆排序，取 Top-K。
  - 随后进行**多阶段语义验证**：
    1. Taxonomy 一致性检查；
    2. 安全不变量一致性检查；
    3. 污点阻断器检查；
    4. LLM 基于警报上下文和检索记忆做最终推理。
  - 只有通过验证的记忆才能贡献到最终 FP/TP 决策，防止文本相似但语义不适用的记忆误伤真实漏洞。

- **阶段 III：记忆演化（Evolving）**
  - 对于每个被验证为误报的新案例，将其作为新示例加入对应记忆，扩展检索键，更新可靠性统计。
  - 频繁得到验证的记忆会增强，无效记忆随时间的衰减逐步弱化，从而让知识库自适应软件生态的变化。

**核心公式化描述**：
- 警报表示为 `A = ⟨trace, cwe, rule, source, sink, analysis⟩`；
- 记忆库表示为 `M = {m1, m2, ..., mn}`；
- 目标学习决策函数 `f(A, M) → {FP, TP}`。
