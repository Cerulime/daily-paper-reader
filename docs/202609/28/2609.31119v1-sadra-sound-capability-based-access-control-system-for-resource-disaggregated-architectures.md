## 摘要
资源解耦将内存和加速器与计算节点分离，并使其可远程访问。这提升了资源共享，但也将本地内核从资源访问路径中移除。在不受信任的主机下，被攻陷的主机软件可能使用过期权限、超越被委托的权限，或重用为另一进程配置的权限。先前工作认为基于能力的访问控制非常适合这些架构。我们对二十二个已有能力系统的系统化梳理发现，没有一个系统同时结合了与主机无关的进程权限验证、在资源处的权威强制执行，以及在远程授权状态过期时仍有效的撤销。

我们提出 SADRA，一种面向资源解耦架构的分布式基于能力的访问控制系统。与主机软件隔离的 SmartNIC 硬件在两点独立检查每个节点间请求：首先在计算节点处根据请求进程的权限进行检查，然后在资源处根据当前权威访问状态再次检查。关联的进程、计算和资源能力使这些检查能够使用本地状态，而无需在访问路径上进行协调。当分布式权限被撤销时，SADRA 会在资源处拒绝后续的依赖访问，而无需等待远程节点更新，同时过期能力状态会另行回收。

我们针对形式化架构模型证明了能力安全性、权限安全性、撤销健全性和强隔离性，并使用 SPIN 对形式化进行了模型检测。我们的 FPGA SmartNIC 原型实现了 89.5 Gbit/s 的总吞吐量，处于非强制执行基线（峰值 90--91 Gbit/s）的逐次运行波动范围内。清理一个包含 128 个能力的子树可在 528 ns 内完成，而访问拒绝不依赖于该清理的完成。

## Abstract
Resource disaggregation separates memory and accelerators from compute nodes and makes them remotely accessible. This improves resource sharing, but also removes the local kernel from the resource-access path. Under an untrusted host, compromised host software may use stale authority, exceed delegated authority, or reuse authority provisioned for another process. Prior work identifies capability-based access control as well suited to these architectures. Our systematization of twenty-two prior capability systems finds that none combines host-independent validation of process authority, authoritative enforcement at the resource, and revocation that remains effective while remote authorization state is stale.   We present SADRA, a distributed capability-based access-control system for resource-disaggregated architectures. SmartNIC hardware isolated from host software independently checks every inter-node request at two points, first at the compute node against the requesting process's authority and again at the resource against the current authoritative access state. Linked process, compute, and resource capabilities allow these checks to use local state without coordination on the access path. When distributed authority is revoked, SADRA denies subsequent dependent accesses at the resource without waiting for remote nodes to update, while stale capability state is reclaimed separately.   We prove capability safety, authority safety, revocation soundness, and strong isolation for a formal architectural model, and model-check the formalization with SPIN. Our FPGA SmartNIC prototype sustains 89.5 Gbit/s aggregate throughput, within run-to-run variation of a non-enforcing baseline that peaks at 90--91 Gbit/s. Cleanup of a 128-capability subtree completes in 528 ns, while access denial does not depend on completion of that cleanup.
