## 摘要
瞬态云资源可显著节省成本，但其不可预测性使其难以用于在资源回收后无法安全重启的应用。现有方法需要修改应用，或依赖粗粒度检查点，而后者的开销限制了其收益。我们提出 ThreadShift，一个可将未经修改的 Linux 应用中的计算密集型线程透明地卸载到廉价瞬态资源上的系统，同时在资源回收时保持正确性。通过在线程粒度上操作，ThreadShift 能够实现快速、细粒度的检查点，并仅卸载那些能从瞬态执行中受益的线程。主要挑战在于，尽管存在跨线程依赖，仍要对单个线程进行检查点。ThreadShift 通过高效跟踪内存依赖、识别每个线程的内存写入，并维护跨机器的一致性来实现这一点。内存保护键（MPK）的三种新颖用法使这些机制变得高效，从而能够在不暂停整个应用的情况下实现快速增量检查点。我们在 x86-64 Linux 上实现了 ThreadShift，并在包括机器学习推理、密码学任务和内存数据处理等工作负载上进行了评估。ThreadShift 可在低至 164 微秒内卸载线程，检查点速度比 CRIU 快达三个数量级，并在商用云上将部署成本降低最多 56%。

## Abstract
Transient cloud resources offer significant cost savings, but their unpredictability makes them hard to use for applications that cannot be safely restarted after reclamation. Existing approaches require application changes or rely on coarse-grained checkpointing, whose cost limits its benefits.   We present ThreadShift, a system that transparently offloads compute-intensive threads of unmodified Linux applications to cheap transient resources while preserving correctness under reclamation. By operating at thread granularity, ThreadShift enables fast, fine-grained checkpointing and offloads only the threads that benefit from transient execution.   The main challenge is to checkpoint individual threads despite cross-thread dependencies. ThreadShift does so by efficiently tracking memory dependencies, identifying per-thread memory writes, and maintaining coherence across machines. Three novel uses of Memory Protection Keys (MPKs) make these mechanisms efficient, enabling fast incremental checkpoints without pausing the entire application.   We implement ThreadShift on x86-64 Linux and evaluate it on workloads including machine-learning inference, cryptographic tasks, and in-memory data processing. ThreadShift offloads threads in as little as 164 us, performs checkpointing up to three orders of magnitude faster than CRIU, and reduces deployment cost by up to 56% on commodity clouds.
