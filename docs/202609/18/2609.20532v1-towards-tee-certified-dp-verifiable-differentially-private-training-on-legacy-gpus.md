## 摘要
机器学习的广泛采用催生了日益增长的政策与监管需求，要求保护敏感训练数据，而差分隐私（DP）正成为一种关键机制。然而，一个研究较少的问题是如何认证训练过程中 DP 的忠实执行：外部验证者应能在不访问私有训练数据的情况下，检查已发布模型是否在适当 DP 保护下训练。现有密码学方法（如零知识证明）提供了强保证，但往往带来难以承受的开销，有时甚至高出数个数量级。可信执行环境（TEE）提供了一种更高效的替代方案，但训练和微调大语言模型所需的多 GPU TEE 支持仍局限于较新的平台，在旧代 GPU 上则缺失或效率低下。为解决这一问题，我们提出一个实用的可验证 DP 训练框架，使用 CPU 侧 TEE 与不可信 GPU 协同。我们的设计解决了一个根本性的效率-安全权衡：完全在 CPU TEE 内训练太慢，而无限制地卸载到 GPU 又可能允许恶意偏离 DP。因此，我们将昂贵的梯度计算卸载到 GPU，同时利用 CPU TEE 通过概率性检查来高效验证梯度上 DP 的正确执行。我们的框架能以高概率检测频繁的完全偏离 DP 的行为；对于本文评估的面向效用的伪造梯度攻击，稀疏偏离带来的效用收益有限，且未显示出可测量的额外成员泄露。实验进一步表明，我们的方法几乎实现了“免费午餐”：与标准基于 GPU 的 DP 训练相比，仅带来适度开销，同时有效约束了对所声称 DP 执行的恶意偏离。

## Abstract
Wide adoption of machine learning has created growing policy and regulatory demand for protecting sensitive training data, with differential privacy (DP) emerging as a key mechanism. Yet a less-studied problem is how to certify the faithful execution of DP during training: an external verifier should be able to check that a released model was trained with proper DP protection, without accessing the private training data. Existing cryptographic approaches, such as zero-knowledge proofs, provide strong guarantees but often incur prohibitive overhead, in some cases by orders of magnitude. Trusted Execution Environments (TEEs) offer a more efficient alternative, but the multi-GPU TEE support needed for training and fine-tuning large language models remains limited to recent platforms and is absent or inefficient on legacy GPUs.   To address this, we propose a practical framework for verifiable DP training using CPU-side TEEs together with untrusted GPUs. Our design addresses a fundamental efficiency-security tension: training entirely inside a CPU TEE is too slow, while unrestricted GPU offloading can allow malicious deviations from DP. We therefore offload expensive gradient computation to GPUs, while using the CPU TEE to efficiently verify the correct enforcement of DP on gradients through probabilistic checking. Our framework detects frequent full deviations from DP with high probability; for the utility-oriented forged-gradient attacks evaluated in this work, sparse deviations provide limited utility benefit and show no measurable additional membership leakage. Experiments further show that our approach nearly achieves a ``free lunch'': it incurs only modest overhead compared with standard GPU-based DP training, while effectively constraining malicious deviations from the claimed DP execution.

## 1. 核心问题与整体含义

- **研究动机**：差分隐私（DP）已成为保护敏感训练数据的核心机制，DP-SGD 被隐私法规和最佳实践广泛推荐。然而，**如何认证 DP-SGD 在训练过程中被忠实执行**却鲜有研究。由于 DP 噪声会降低模型效用，模型所有者有强烈动机在声称提供 DP 保护的同时减少甚至省略噪声。现实中已出现 Apple DP 框架被配置为禁用 DP 的案例。
- **可验证 DP 的目标**：外部验证者（如监管机构）应能在**不访问私有训练数据**的前提下，检查已发布模型是否按声明的 DP 协议训练，并获得可公开验证的证据。
- **现有方案的两难**：
  - **零知识证明（ZKP）**：保证强，但开销巨大，即使 0.01B 参数的小模型也可能超过 1000×，不实用。
  - **TEE 方案**：更高效，但多 GPU TEE 支持仅限最新平台（如 NVIDIA Blackwell B200）；Hopper 架构依赖加密 bounce buffer 开销大；V100/A100/RTX 4090 等旧代 GPU 完全不支持 TEE。
- **核心矛盾（效率-安全权衡）**：完全在 CPU TEE 内训练太慢（8.0×–9.2× 开销），而无限制地将计算卸载到不可信 GPU 又会引入恶意偏离 DP 的风险。

## 2. 方法论

### 核心思想
- **CPU-TEE + 不可信 GPU 的混合架构**：将昂贵的梯度计算卸载到不可信 GPU，CPU TEE 负责可信随机性、模型/优化器状态维护、DP 噪声生成，并通过**概率性检查**验证 GPU 提交的梯度是否遵守 DP 约束。
- **容忍稀疏偏离、检测密集偏离**：按恶意迭代次数 M 将偏离分为稀疏（M < M̄）与密集（M ≥ M̄）。对评估的面向效用攻击，稀疏偏离效用收益有限且无额外可测隐私泄漏；密集偏离通过概率验证以高概率检测。

### 关键技术细节
- **基础协议**：每步 GPU 计算 per-example 梯度、裁剪、聚合并提交给 TEE；TEE 用隐藏 Bernoulli 硬币 Vt ~ Bern(p) 决定是否审计该步；审计时 TEE 重计算并与 GPU 结果比较，超差则中止；TEE 执行 DP 噪声生成与参数更新。
- **检测保证**：对 M_full 次完整偏离，检测概率为 `P_det = 1 − (1 − p)^{M_full}`。
- **两阶段数值验证（应对 GPU-TEE 浮点差异）**：
  - 结构不变量（每步）：`‖ḡ_t^GPU‖₂ ≤ C(1+10⁻⁴)`，否则拒绝。
  - **Body 路径**：若 `z_t^32 ≤ τ_abs`，将差异计入累积账本 `Z_sub`，超过 `K_sub` 中止。
  - **Ambiguity 路径**：若 FP32 差异过大，用 FP64 重算，若 `z_t^64 ≤ ρ_amb` 则接受但计入 `S_amb`，超过 `K_amb` 中止。
  - **Hard rejection**：`z_t^64 > ρ_amb` 直接拒绝。
- **数值容差安全预算**：`G_extra = G_sub + G_amb`，满足 `Pr[G_tol > G_extra 且仍接受] ≤ β_extra`。用 Freedman–Bernstein 界（FP32 路径）和精确二项分布（FP64 路径）推导。
- **效率优化**：
  - **通信高效拆分执行**：GPU 侧完成裁剪聚合，仅传 O(d) 的聚合梯度而非 O(Bd) 的 per-example 梯度；TEE 提交后释放噪声种子，GPU 本地重建噪声并同步更新，反向通信降至种子大小。
  - **Hungry updating（延迟验证）**：TEE 提交后立即执行延迟关键的 DP 更新，将验证任务放入后台队列，由并行 worker 异步完成，避免阻塞训练。

### 算法流程（文字描述）
1. TEE 初始化可信权重、优化器状态、主种子，并发送给 GPU。
2. 每轮：GPU 计算梯度并提交；TEE 秘密采样 Bernoulli 硬币；若被选中则重算验证（FP32→必要时 FP64）；验证通过后 TEE 释放噪声种子；GPU 重建噪声、执行优化器更新。
3. 训练结束且所有验证任务完成后，TEE 发布最终模型和认证证书。

## 6. 主要结论与发现

- **效率接近“免费午餐”**：在 LLM 任务上，本方案仅带来 **4.4%–14.9%** 开销（p=0.10），远低于 TEE-only 的 **8.0×–9.2×**；CIFAR-10 上 TEE-only 约 20×，本方案在 p=0.02/0.05 下约 +13%/+30.6%。
- **安全性**：M_full=50 次完整偏离在 p=0.10/0.15 下检测概率分别为 99.5%/99.97%。数值容差安全预算 (G_extra, β_extra) 为 RoBERTa (5.48, 0.05)、GPT-2 (9.50, 0.05)、CIFAR-10 (2.51, 0.05)。
- **稀疏偏离影响有限**：M ≤ 50 时所有任务效用提升 <1 分（Purchase 例外约 +2.3 分）；CIFAR-10 在 ε=2/4 下即使 M=120 也几乎无收益，仅 ε=8 时有效。
- **无额外 MIA 泄漏**：SHAPOOL AUC 与诚实 DP 基线相同或相差 ≤0.01；IMIA 分数远低于非私有模型，且随 ε 或 M 增大无一致单调增长。
- **验证器形状**：小 K（K ≤ 2）更优，增大 K 增加延迟但吞吐收益有限。

## 7. 优点

- **实用性强的架构设计**：首次系统性解决旧代 GPU 上可验证 DP 训练问题，兼容现有 CPU-TEE 与无 TEE 的旧 GPU，避免依赖昂贵的新硬件。
- **明确的安全-效率权衡分析**：将偏离按频率分类，用实验支撑稀疏偏离的低收益/低泄漏，为容忍策略提供依据。
- **数值容差作为攻击面的识别**：指出 honest GPU-TEE 浮点差异本身是攻击面，提出“无免费偏差”原则，用账本机制计量容忍偏差，并给出解析高概率界。
- **工程优化到位**：通信从 O(Bd) 降至 O(d)、种子反向传输、hungry updating 异步验证，使开销可控。
- **诚实界定保证范围**：明确区分形式化保证（G_extra、检测界）与经验观察（M=50、steering-scale 转换），并标注每条数据的证据等级（Table 8），学术诚实度高。
- **攻击者最强放置**：攻击步选择由对手最优决定而非随机，评估更保守。

## 8. 不足与局限

- **攻击覆盖有限**：仅评估 Current/Nearest/Final 三种 steering 攻击，未穷尽所有效用导向或隐私导向的稀疏攻击；未运行均匀随机对照。

- **经验结论的迁移假设**：M=50 阈值、steering-scale 转换系数均在不同轨迹家族上测量，迁移到部署家族属于**经验假设**，非形式化保证。
